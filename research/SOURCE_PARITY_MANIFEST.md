## Source-first UI workflow (permanent, from Phase 6)

Before implementing or substantially changing any visual SwiftUI/AppKit component, inspect in this order and record what was used:

1. **Droppy source** (`~/Downloads/Droppy-main`) — read the complete relevant view/controller (dimensions, spacing, radii, typography, opacity, motion, hover/popover lifecycle).
2. **ExploreSwiftUI** (exploreswiftui.com) — the most relevant native SwiftUI technique. The site states it is an unofficial educational resource with no reuse license, so adopt techniques, never copy large code blocks.
3. **Droppy screen recordings** in `research/*.mov` — skim with a contact sheet, inspect only relevant timestamps, record concise observations.
4. Only then a native macOS fallback. Never claim parity that was not inspected.
