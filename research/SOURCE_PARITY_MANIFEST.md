# Source parity manifest — Expanded Workspace 2.0 (2026-09-30)

Reference sources were read in full before porting. Licensing posture:

- **Droppy** — https://github.com/1of1Adam/Droppy, upstream HEAD `dd2d16ccbdc6aa22b456e199442b43a07aa446af`
  (identical to the local checkout `/Users/makeiteasy3/Downloads/Droppy-main`). GPL-3.0 + Commons Clause.
  Reused under the user's authorization **for this private, personal build only**. Files that contain
  Droppy-derived code carry a provenance header. A separate licensing audit is required before any public
  or commercial distribution.
- **AgentNotch** — https://github.com/AppGram/agentnotch, HEAD `4139d6fd7b90a060b90b17ed20e0878b0641cc1a`.
  The README declares MIT, but the repository contains **no LICENSE file**. Therefore no substantial source was
  copied; only numeric constants (colors) and observable behavior were adopted.
