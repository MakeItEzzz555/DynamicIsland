## Genuine external dependencies

Remote sharing requires a selected provider, account and privacy/cost authorization. A secure Lock Screen surface requires a supported macOS capability; DynamicIsland does not bypass the system login surface. Unsupported codecs/features remain explicitly unavailable. These dependencies do not excuse unfinished independent Settings controls listed above.
